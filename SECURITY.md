# Security

Meter reads credentials owned by other coding tools. Please do not post a suspected vulnerability, token, cookie, authentication file, or personal usage record in a public issue.

Use [GitHub's private vulnerability reporting](https://github.com/justn-hyeok/meter/security/advisories/new) to send a report to the maintainer. Describe the affected Meter version, the impact, and steps to reproduce with redacted data. The advisory keeps discussion private while the report is assessed and a fix is prepared.
